# THE WORKING EDITION

UI/UX 기획과 화면 구현 과정을 함께 보여 주는 김지영의 React 기반 개인 포트폴리오입니다. 프로젝트의 문제 정의, 화면 설계, 구현 결과와 작업 회고를 하나의 스크롤 흐름으로 구성했습니다.

## 주요 섹션

- INTRO / WORK INTRO
- HYUNDAI MOTORSTUDIO 팀 프로젝트
- VIVIENNE WESTWOOD / COS KOREA 개인 리디자인
- AI VIDEO CONTENTS
- CLONE CODING
- SKILL / ABOUT / CONTACT

## 주요 기술

- React, JavaScript, HTML, CSS, SCSS
- GSAP, ScrollTrigger, Lenis
- Three.js
- Vite

디자인 및 콘텐츠 작업에 사용한 도구와 구체적인 활용 범위는 사이트의 SKILL 섹션에서 확인할 수 있습니다.

## 로컬 실행

Node.js와 npm이 설치된 환경에서 다음 명령을 실행합니다.

```bash
npm install
npm run dev
```

프로덕션 빌드는 다음 명령으로 확인합니다.

```bash
npm run build
```

## 폴더 구조

```text
my-portfolio/
├─ docs/       프로젝트 명세, 레퍼런스 조사, 콘텐츠·에셋 기록
├─ public/     이미지, 영상, 폰트 등 정적 에셋
├─ src/
│  ├─ components/  섹션 및 공통 UI 컴포넌트
│  ├─ data/        프로젝트와 챗봇 콘텐츠 데이터
│  ├─ pages/       프로젝트 상세 화면
│  └─ styles/      섹션별 스타일
└─ vite.config.js
```

## 에셋 관련 안내

포트폴리오에는 프로젝트 설명을 위한 브랜드 로고, 웹사이트 구현 캡처, Figma 결과물과 영상이 포함되어 있습니다. 각 브랜드 관련 에셋의 권리는 해당 권리자에게 있으며, 본 저장소의 자료는 개인 포트폴리오와 학습 결과 설명을 위한 용도로 사용합니다. 에셋을 별도 프로젝트나 상업적 용도로 재사용하지 마세요.

세부 구현 기준과 에셋 출처 기록은 [`docs`](./docs) 문서를 참고해 주세요.
