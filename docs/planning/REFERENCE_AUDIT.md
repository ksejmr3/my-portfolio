# 전지현 포트폴리오 레퍼런스 조사

조사일: 2026-10-15. 근거: 사용자가 제공한 61.56초, 1920×1040 데스크톱 화면 녹화(`pr구현/전지현 포트폴리오 — From Office to Design - Chrome 2026-10-15 12-50-32.mp4`). 1초 간격 프레임과 연속 프레임을 살폈다. [실제 사이트](https://persona1-pi.vercel.app/)는 웹 도구와 로컬 HTTP 양쪽에서 접속에 실패했다. 따라서 아래의 '확인'은 녹화 화면 기준이며 현재 사이트 상태나 구현 코드를 뜻하지 않는다. 시간은 녹화 재생 시각의 근삿값이다.

## 확인한 화면 구조

| 시각 | 화면 | 관찰한 배치 |
|---|---|---|
| 0–6초 | INTRO | 검은 배경, 중앙의 큰 산세리프 문구와 기울임 세리프 단어. 이어 경력에서 디자인으로 이동하는 소개 문장이 다중 행으로 나타난다. 위쪽에는 둥근 밝은 내비게이션 바. |
| 6–9초 | 가치 문구 | 세로 이미지 카드 3장이 중앙에 모이고 CLARITY, GROWTH, EMPATHY 문구가 카드 위에 놓인다. |
| 9–13초 | 짧은 ABOUT와 WORK 진입 | 흰 바탕의 자기소개 문장 왼쪽, 세로 인물 사진 오른쪽. 이어 큰 기울임 `selected projects` 타이틀과 프로젝트 분류 화면. |
| 14–29초 | WORK / 상세 사례 | ZARA 웹 리뉴얼의 큰 기기 목업과 메타데이터. 뒤이어 어두운 배경에서 목표, 타이포그래피, Before & After, 에디토리얼 디자인, 협업을 연속 장면으로 설명한다. 이후 시장 조사, 인터뷰, 방향 설정, 와이어프레임을 보여준다. |
| 30–43초 | 다른 개인 작업 | ONDA, LUMA 등의 웹 리뉴얼과 이미지 중심 장면, 짧은 콘텐츠 사례, 클론 코딩 장면이 이어진다. 이들이 별도 URL인지 한 페이지 내부인지 확인할 수 없다. |
| 44–48초 | SKILL | 밝은 바탕의 매우 큰 타이틀이 화면 밖으로 일부 잘리고 검은 기술 목록 화면으로 넘어간다. |
| 48–57초 | ABOUT | 검정과 흰색으로 나뉜 큰 제목 이후 여러 작은 이미지가 가로줄→원형→확대 배치로 바뀌는 시퀀스. |
| 57–61초 | CONTACT / footer | 어두운 바탕의 인물 이미지와 짧은 마무리 문장. 아래에 INTRO/WORK/SKILL/ABOUT/CONTACT 목록, 연락 링크, 위로 가기 화살표가 보인다. |

## 시각 원칙

- 검정, 흰색, 중간 회색의 장면이 교차한다. 프로젝트마다 이미지 색이 중심이 되고 공통 UI는 무채색이다.
- 제목은 큰 산세리프와 가는 기울임 세리프를 섞는다. 본문과 메타는 훨씬 작다. 실제 폰트명과 CSS 수치는 녹화만으로 확인할 수 없다.
- 1920px 녹화 기준 상세 장면은 이미지가 화면 왼쪽 약 40–55%, 설명이 오른쪽 약 30–40%를 차지하는 경우가 많다. 사례에 따라 전면 이미지나 중앙 목업도 쓴다. 이는 프레임의 대략적인 시각 비율이다.
- 상단/하단의 여백이 크고 한 화면에 하나의 메시지를 둔다. 조사 자료는 화면 안에서 읽기 어려운 크기로 축소되어 있으므로 신규 사이트에서는 원본 확대 경로가 필요하다.
- 상세페이지는 큰 목업 → 의도/비교 → 조사/과정 → 결과 사례의 흐름으로 보인다. 모든 프로젝트가 같은 장 수를 갖는지는 확인되지 않는다.

## 녹화에서 확인한 움직임과 구현 판단

| 화면의 결과와 발생 시점 | 입력과 확인 수준 | 적합한 구현 방향 |
|---|---|---|
| 2–6초 INTRO 문구가 화면 위로 이동하고 다음 문구가 나타남 | 녹화 중 스크롤 진행과 함께 보임. 정확한 pin 여부 미확인 | 단순 등장/이동은 CSS 가능. 스크롤 진행률과 정확히 연결할 때만 ScrollTrigger 검토 |
| 6–9초 3장의 카드가 밝은 사진에서 어두운 텍스트 카드처럼 바뀜 | 연속 프레임에서 변화 확인. hover 또는 스크롤 중 어느 입력인지는 미확인 | 상태 전환이면 React 상태/CSS. 스크롤 연동이면 ScrollTrigger. 원인 확인 전 구현 보류 |
| 9–12초 검은 화면에서 흰 ABOUT 화면으로 바뀌며 텍스트와 사진 등장 | 녹화의 연속 장면에서 확인 | CSS opacity/transform과 섹션 배경. 정확한 트리거는 미확인 |
| 13–16초 WORK 진입 뒤 ZARA 상세가 등장 | 화면 이동 확인. 클릭 여부 및 URL 변경은 영상에서 읽을 수 없음 | 처음에는 의미 있는 링크와 라우팅/앵커로 구성. 페이지 전환 애니메이션은 보류 |
| 16–29초 상세 사례의 이미지/문구가 화면 단위로 연속 교체 | 스크롤이 진행됨. 일부 장면은 옆 방향으로 이동하는 듯 보이나 실제 가로 스크롤인지 미확인 | 기본 세로 문서 + CSS 레이아웃으로 시작. pin/가로 이동은 후속 확인 뒤 결정 |
| 48–55초 ABOUT의 작은 이미지들이 한 줄에서 원으로 재배치되고 확대 | 연속 프레임에서 변화 확인. 스크롤에 따라 나타나는 것으로 보이나 구현 방식 미확인 | 동일 효과를 채택할 때 GSAP/ScrollTrigger가 적합한 후보. 콘텐츠를 위해 꼭 필요한지 먼저 검토 |
| 57–61초 연락처와 위로 가기 화살표 표시 | 녹화에서 요소 확인. 화살표 클릭 결과는 미확인 | 일반 링크와 CSS로 충분 |

역방향 스크롤, 카드 hover, 모바일 레이아웃, 로딩 애니메이션의 첫 프레임 이전 상태, 페이지 전환 방식, sticky/pin의 실제 CSS·JS 구현, 이미지 전환 트리거, 기기별 분기 및 reduced-motion 동작은 확인하지 못했다. 영상에는 데스크톱 한 뷰포트만 나온다.

## 신규 포트폴리오 적용 방향

큰 제목과 작은 설명의 위계, 검정/흰색 장면의 리듬, 프로젝트마다 한 장면에 하나의 논점, 이미지와 설명의 넉넉한 좌우 배치를 참고한다. 현대 조사 보드는 원본 이미지로 보존하고 확대 보기를 제공한다. ABOUT의 이미지 재배치나 상세 장면의 전환 효과는 실제 콘텐츠가 준비된 뒤 필요성과 모바일 대체 흐름을 확인한다. 레퍼런스의 사진, 텍스트, 소스 코드, 정확한 장면 구성은 복제하지 않는다.
