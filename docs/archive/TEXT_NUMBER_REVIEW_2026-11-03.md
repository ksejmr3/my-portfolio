관찰 사항: 390px에서 고정 마스코트가 스크롤 위치에 따라 일부 영상 설명·SKILL 목록 우측과 겹치는 기존 구성이 보인다. 이번 변경으로 생긴 겹침은 아니며 챗봇·보호 인터랙션의 위치를 임의로 바꾸지 않았다. 이전에 확인한 보호 PROFILE의 문장 끝 줄바꿈도 유지했다. 따라서 사이트 모든 위치에 겹침·줄바꿈 문제가 전혀 없다고 판정하지 않는다.

## 7. 5개 해상도 시각 검증

실제 로컬 Vite 페이지를 headless Chrome에서 열고 전후 원본 PNG와 computed style을 함께 비교했다. `sheet-*-A.png`는 INTRO 및 HYUNDAI 전후, `sheet-*-B.png`는 개인 작업·AI·클론·SKILL·ABOUT·CONTACT 비교용이다. 원본 PNG도 별도로 보관했다.

| 해상도 | 수정 영역 검증 | HYUNDAI 최종 개요/기여 줄 수 | 가로 넘침 |
|---|---|---:|---|
| 1920×1080 | 고정 INTRO 문구 없음, 프리뷰 위치 유지, 두 본문 그룹·보드 균형 확인 | 2 / 2 | 없음 |
| 1440×900 | 제목 축소, 구분선 제거, 두 문단·본문 폭 확인 | 2 / 2 | 없음 |
| 1024×768 | 두 열 구성 유지, 제목과 설명 분리·보드 배치 확인 | 3 / 2 | 없음 |
| 768×1024 | 세로 배치, 두 문단 사이 18px, 자연 높이·다음 콘텐츠 연결 확인 | 2 / 2 | 없음 |
| 390×844 | 제목 40px·본문 16px 유지, 두 문단 각 3줄, 단어 단위 자연 줄바꿈 확인 | 3 / 3 | 없음 |

5개 해상도 모두 삭제된 노드 수 0, 소개 p 두 개, 구분선 0px, 검사한 본문 가로 잘림 없음. 보호 HYUNDAI 목업·SELECTED SOLUTIONS·PROCESS의 높이·padding·텍스트 서체·크기·박스 측정값은 전후 일치한다. INTRO 프리뷰와 제목의 박스 좌표도 전후 일치한다. 이전 삭제 UI 재노출 없음, 프로젝트 순서·총수·연결 주소 동일함을 확인했다.

768/390에서는 소개 전체 높이가 각각 61/42px 자연스럽게 줄었다. 그만큼 뒤 섹션의 문서상 절대 위치는 앞당겨지지만, 기존 스크롤 계산이 새 위치를 다시 측정한다. 화면 높이나 스크롤 거리를 강제로 고정해 삭제된 텍스트의 빈 행을 남기지 않았다.

- `git diff --check`: 통과. 새 lint·test 스크립트나 의존성을 추가하지 않았다.

## 10. 미검증 범위

- GPU가 비활성화된 테스트 브라우저에서 PROFILE의 WebGL 말림 효과를 실제 GPU 화면으로 검증하지 못했다. 해당 파일·셰이더는 변경하지 않았다.
- 실제 휴대폰·터치 제스처·모바일 OS 조합을 검증하지 않았다. 지정 viewport와 wheel/클릭 검증 범위다.
- 외부 프로젝트 배포 상태, 실제 메일 발송·전화 연결은 실행하지 않았다. 원래 링크 값이 유지되는지 비교했다.
- 이미지·영상 내부의 모든 작은 번호·텍스트와 인터랙션 모든 중간 프레임을 전수 검사한 것은 아니다. 보호 소스 비교·대표 진행 상태·복귀 및 요청한 화면 구성을 검증했다.
- 추가 번호의 삭제·재배치는 승인 대상이므로 구현하지 않았다. 현재 혼재를 임의로 전역 연속 번호로 재설계하지 않았다.
