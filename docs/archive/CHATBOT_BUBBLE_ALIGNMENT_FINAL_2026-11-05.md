## 1. 실제 보이는 캐릭터를 기준으로 측정

기존 보고서의 7px은 **꼬리 끝→PNG 이미지 박스** 간격이었다. 원본 PNG를 Canvas로 읽어 투명 픽셀을 제외한 윤곽을 구하고, 실제 렌더링 크기·부유 위치·hover scale/rotate 행렬에 맞춰 화면 좌표로 변환했다. 원본 파일은 수정하지 않았다.

- PNG 원본: 1254×1254. alpha≥128 윤곽의 상단은 y157이다. 투명 여백 때문에 박스의 위쪽이 캐릭터 머리 위쪽과 같지 않다.
- 주 지표: 꼬리 삼각형 끝에서 **alpha≥128인 캐릭터 윤곽까지의 최소 직선거리**(CSS px).
- 교차 확인: 희미한 가장자리도 포함하는 alpha≥16 윤곽으로 다시 측정하고, 말풍선 본체/꼬리 삼각형에 실제 캐릭터 픽셀이 들어오는지도 검사했다.
- CSS 박스만으로 완료 판단하지 않았다. 원본 PNG의 윤곽·object-fit:contain·실제 크기·transform-origin·hover 행렬을 반영한 거리다. 서로 다른 색의 배경 스크린샷을 비교해 윤곽을 추정한 값이 아니다.

| 해상도 | 실제 윤곽 거리 이전→이후 (alpha≥128) | 축소량 | alpha≥16 이전→이후 | hover 후 실제 윤곽 거리 |
|---|---|---|---|---|
| 1920×1080 | 20.56 → 9.23px | 11.32px | 20.50 → 9.18px | 7.16px |
| 1440×900 | 20.56 → 9.23px | 11.32px | 20.50 → 9.18px | 7.16px |
| 1024×768 | 20.56 → 9.23px | 11.32px | 20.50 → 9.18px | 7.16px |
| 768×1024 | 14.92 → 7.66px | 7.26px | 14.89 → 7.63px | 6.41px |
| 390×844 | 14.92 → 7.66px | 7.26px | 14.89 → 7.63px | 6.41px |

결과적으로 desktop은 **20.56→9.23px**, 900px 이하는 **14.92→7.66px**로 가까워졌다. 첨부 스크린샷의 10–12px 축소 요청은 desktop에서 약11.32px로 반영했고, 모바일은 표시 크기52/88 비율을 고려해 약7.26px만 줄였다.

7. 실제 캐릭터와 본체/꼬리는 부유·hover·등장·퇴장 중 겹치지 않음.
